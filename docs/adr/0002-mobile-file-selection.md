# ADR 0002: системный выбор файлов

- Status: accepted
- Date: 2026-07-16

## Decision

Для импорта из файловой системы используется официальный Flutter-плагин
`file_selector`. Импорт из меню «Поделиться» остаётся на
`receive_sharing_intent` и дополняется нативными Android intent filters и iOS
Share Extension.

## Context

Первоначально рассматривался `file_picker`, как в ТЗ. Его актуальная версия не
собралась с Android Gradle Plugin 9 из закреплённой версии Flutter. Понижение до
старой версии ухудшало бы безопасность и увеличивало стоимость будущего
обновления.

## Consequences

- Выбор одного EPUB/TXT работает через нативный системный диалог без лишнего UI.
- Web API плагина не используется и Flutter Web по-прежнему не входит в сборку.
- Share flow остаётся отдельным платформенным контуром и проверяется на обеих
  ОС перед релизом.
